#### How to run basic buy/sell trade with syncophancy settings 

1. Navigate to the NegotiationArena repository 
2. Switch to `wh` branch by running `git checkout wh` 
3. Open `NegotiationArena/scripts/run_negotiation.sh` 
4. Change constants marked by capitalization
5. Run `./scripts/run_negotiation.py` 

#### Notes 

1. For development or debugging, please use the notebooks in `NegotiationArena/notebooks/test.ipynb` 
2. Each negotiation round costs less than a 10 cents, but it can accumulate quickly, so please be cautious!
